# UI readiness contract

The `ui` catalog in `build.gradle` is authoritative. It includes ChemMaster/wire layouts, shared chrome/geometry/title routing, gameplay-window keyboard-capture movement dispatch, wire lifecycle, pointer workspace/routing/mode, bitmap-font and CPU ordered-paint tests. `preview` adds the production-driven `ProductionUiPreviewTest`.

The generator invokes the production ChemMaster and airlock-wire painters for 48 full-viewport cases (both screens, viewports 320×240 and 640×360, GUI scales 1–3, four generated states per screen/scale/viewport), detail crops, and two contact sheets. Readiness validates the current invocation's manifest producer, 48-case coverage/matrix, declared source/screens/scales/viewports, two contact sheets, and all listed PNG paths (inside the preview output, nonempty and decodable). Invalid or incomplete evidence is FAIL when the generator ran; missing current output remains UNVERIFIED. CPU raster/font scope is unstyled left-to-right Components using the selected bitmap provider; unsupported styled content/resource stacking and native GPU/scissor effects are not covered.

Generated images require independent opening/review against selected bitmap-render cases. Record current findings and reviewer in `ACCEPTANCE.md` or the linked invocation evidence; this contract does not permanently certify a visual PASS. Review is not automatic aesthetic certification, native/GPU parity, or owner acceptance. Prototype/runtime unit checks do not prove live runtime consumption; authenticated admission and native cursor behavior remain separate evidence boundaries. Retain the composition policy in root `AGENTS.md`.
