# UI readiness contract

The `ui` catalog in `build.gradle` is authoritative. It includes ChemMaster/wire layouts, shared chrome/geometry/title routing, gameplay-window keyboard-capture movement dispatch, wire lifecycle, pointer workspace/routing/mode, bitmap-font and CPU ordered-paint tests, examine popup refresh/scroll policy, shared examine numeric precision/style/fallback coverage, and Gas Analyzer workspace/input policy. `preview` adds the production-driven `ProductionUiPreviewTest`.

Gun/target-action additions assert the gun ammo-counter painter and hand-ammo projection/preview, plus target-action list layout and window preview typography/painting. These are bounded JVM/CPU tests, not native/GPU rendering, closed-effect-mesh visual verification, visual review, or owner acceptance; GPU-native remains excluded from this catalog category.

The generator invokes the production ChemMaster and airlock-wire painters for 72 full-viewport cases (both screens, viewports 320×240 and 640×360, GUI scales 1–3, eight ChemMaster states and four wire states per screen/scale/viewport), detail crops, and two contact sheets. Readiness validates the current invocation's manifest producer, 72-case coverage/matrix, declared source/screens/scales/viewports, two contact sheets, and all listed PNG paths (inside the preview output, nonempty and decodable). Atmos preview readiness additionally invokes the production Atmos machine and air-alarm painters for 210 cases (35 unique states × two viewports × three scales) and one contact sheet under `build/reports/feature-readiness/previews/atmos`. Analyzer preview invokes `GasAnalyzerPaint.paint` for 78 deterministic cases: eight air states plus `pipe-vacuum`, `pipe-mixed`, `device-mixer`, `device-mixer-scrolled`, and `unary-vent`, each at 320×240 and 640×360, scales 1–3, plus one contact sheet. `distance-0` replaces `local-mixed` in the air matrix. Readiness requires current producer/source hash and `moonstation14:atmosphere_analyzer` identity, the full matrix, contained/decodable PNGs with matching SHA-256 and the contact sheet. Missing current generator output is UNVERIFIED; invalid or incomplete evidence is FAIL when the respective generator ran. `closed` is intentionally not a painted state because close dismisses this nonmodal workspace. Across these previews, CPU raster/font scope is unstyled left-to-right Components using the selected bitmap provider; unsupported styled content/resource stacking and native GPU/scissor effects are not covered.

Generated images require independent opening/review against selected bitmap-render cases. Record current findings and reviewer in `ACCEPTANCE.md` or the linked invocation evidence; this contract does not permanently certify a visual PASS. Review is not automatic aesthetic certification, native/GPU parity, or owner acceptance. Prototype/runtime unit checks do not prove live runtime consumption; authenticated admission and native cursor behavior remain separate evidence boundaries. Retain the composition policy in root `AGENTS.md`.
