# Syringe prototype parity

Verified against Space Station 14 revision `c9df5ef5d675b0d1d226828bddf6b78c28502d91`. Upstream prototypes are `BaseItem -> BaseSyringe -> Syringe`; injector modes compose `BaseInjectMode` / `BaseDrawMode` with `BaseSyringeMode`. Local typed `MedicalItemData.SyringePolicy` represents Tiny size, 15u capacity, initial draw mode, allowed modes, 5u selected default, need-hand, initial-hand-change cancellation, .1 movement threshold, `ignore_mobs=false`, and `ignore_closed=true`. `InjectorModeData` represents mode kind, transfer choices [5,10,15]u, `ignore_delay_for_volume=5`, mob/container delays, incremental delay, and self/downed modifiers. Upstream injection targets the `bloodstream` solution (not a separate chemicals solution); self and downed modifiers use self-first priority rather than multiplication, with downed based on `StandingState.IsDown`. The component breaks on movement and damage. Basic syringe sound is none. These are prototype/catalog contracts only: runtime consumption for bloodstream transfer, modifier priority, break behavior, and target state remains pending. No item or persistent stack data is included in this unit.
