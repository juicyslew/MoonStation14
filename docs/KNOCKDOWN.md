# Visible knockdown projection

`CharacterControlSystem.applyParalyze` applies the existing authoritative `knockdown` status alongside stun. The existing status attachment's normal server-to-client synchronization is the projection source; `isKnockedDown` reads the resolved status snapshot on both sides. No extra packet, fake bed/sleep pose, or new status lifecycle is used. The living-entity renderer applies a horizontal Z rotation only while that status is active, restoring vanilla rotations automatically when it expires. Status expiration, status removal, and reducer duration rules are unchanged. Stun without knockdown does not affect this pose. Death, sleep, passenger, spectator, flight, swimming/water, climbing, and vanilla Dinnerbone/Grumm upside-down-name rendering are excluded from the replacement rotation.

It does not implement SS14 standing-state physics, collision changes, falling behavior, crawling, or their component/prototype composition. Existing paralyze action/movement gating remains authoritative and independent of visual rotation.
