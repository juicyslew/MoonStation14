# M10 — cable tint, face geometry, and depth occlusion

## Changes

The cable placeholder palette is now a pure tier-backed value: HV remains red-orange, MV remains yellow-orange, and APC uses normalized `(0, 128/255, 0)`, matching Robust `Color.Green` used by SS14's `CableApcExtension` prototype. Thin cable quads render after particles with depth testing explicitly enabled, `GL_LEQUAL` (515), and depth writes disabled so the strips remain surface overlays without passing through nearer world geometry. A `finally` path restores depth writes, `GL_LEQUAL`, enabled depth testing, and enabled culling.

Before drawing a synchronized node, the renderer confirms its chunk is loaded, the host is non-air and has collision, and the requested attachment face is sturdy. This suppresses stale records after host removal or invalid/occluded face changes without requesting chunks. Both steel and white station-floor tile finishes conceal UP-face cable visuals; removing either finish (`NONE`) reveals the cable again. The floor top-face strip continues to sit just above the block top, and its in-plane axis is explicitly face-oriented; neighbor work remains bounded by the existing nearby cache and visible-record cap.

If the cache returns records but every one is concealed or invalid, no vertices are written. Minecraft 1.21.1's `BufferBuilder.buildOrThrow()` throws `IllegalStateException` for that empty builder (`build()` returns null after finalizing it), so the renderer now uses `build()` and uploads only a non-null mesh. The depth-state restoration remains in the existing `finally` path, including this empty-mesh path. Ordinary visible cable joins now query the already-built `HashSet<CableFaceNode>` using only the at-most-eight geometric neighbor positions (four tangent steps and four edge turns), then confirm candidates through `PowerTopology.cableEdge`. This removes the per-visible-node scan of the full visible-node list while preserving tier matching, stable result order, and visibility filtering for concealed tile faces.

## Validation and limits

Pure tests cover deterministic tier palette values, APC green equivalence, concealment/reveal for both finishes, tangent face-local strip orientation, and indexed adjacency's eight-candidate bound for all six faces (including diagonal rejection). Minecraft's pinned BufferBuilder behavior was checked from the resolved 1.21.1 NeoForge artifact using `javap`. The required `compileJava test --tests '*CableVisual*' --no-daemon` command was attempted but failed during compile with unrelated missing symbols in concurrently changing atmosphere, power-sync, and player-body-control files, before tests could run. `git diff --check` passed (with only Git line-ending normalization notices). No manual Minecraft graphics run was performed; visual appearance, GPU-specific state interaction, and in-world floor acceptance remain owner acceptance work.
