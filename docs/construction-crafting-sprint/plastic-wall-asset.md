# Plastic wall texture provenance

The full-cube Minecraft plastic-wall texture is the unmodified SS14 `full.png`
from `Resources/Textures/Structures/Walls/plastic.rsi`, verified at pinned
revision `c9df5ef5d675b0d1d226828bddf6b78c28502d91`. The upstream RSI metadata
declares CC-BY-SA-3.0 and attributes the original wall artwork to
`https://github.com/vgstation-coders/vgstation13/raw/99cc2ab62d65a3a7b554dc7b21ff5f57c835f973/icons/turf/walls.dmi`.
The imported binary is accompanied by an adjacent license notice. It remains a
flat full-cube material texture; it is not a copied 3D model.
