# ChemMaster output sprint

**Status: CLOSED — owner accepted.** ChemMaster output is implemented and the owner confirmed the final retest worked. See `HANDOFF.md` for current architecture, validation, and remaining limitations; this document preserves the sprint scope.

## Goal and boundaries

Add an Output tab and a removable inserted-output slot to ChemMaster. Support the canonical 30-unit chemistry bottle and pill canister (5×2 grid, ten cells, one pill per cell); produce usable 20-unit pills, up to 20 variants. Packaging draws an exact whole-mixture amount either from BUFFER (default) or INPUT (beaker). The operation is server-authoritative and conservation-preserving. Spawn pills owned inside the inserted canister; never spawn bottles or canisters from the machine. Registered empty bottles/canisters may be supplied through ordinary world spawning, creative mode, or fixtures. Controls and validation use resolved source, capacity, power, range, lifecycle and eligibility rules. Keep input and output slots distinct. Do not confuse the existing packaging bottle's 30-unit capacity with DrinkBottle's 100-unit capacity.
