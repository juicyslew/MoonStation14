SS14 `StorageComponent.OpenOnActivate` defaults true; no extra local field is needed for these supported hosts. Transfers still require existing server snapshot/token authority.

`PILL_TYPE` is a persistent/synchronized 0–19 item-stack value. Its presentation property is registered in the existing `ModSpecialProperties` owner; assets/models and their separate upstream attribution are supplied by the assigned asset worker.

Bottle capacity is resolved as 30u. Existing `ReagentSystem` target transfer now consults the resolved item reaction capability; local pill storage denies reactions. Ordinary pill ingestion still uses the existing transactional body/stomach reaction path. Source contents too large for available stomach room reject unchanged rather than partially digesting and deleting a single-use pill. No force-feed route is claimed.

For that exact whole-pill capacity rejection, the timed completion now distinguishes a valid full-dose plan that cannot transfer the complete source from all other denial/recovery paths. Only the controlled actor receives the localized actionbar text `You can't swallow any more!`; no owner means no message. The English text and swallow verb mirror `Resources/Locale/en-US/nutrition/components/ingestion-system.ftl` (`ingestion-you-cannot-ingest-any-more`; local actionbar delivery adapts SS14 popup feedback). SS14's `IngestionSystem` (`Content.Shared/Nutrition/EntitySystems/IngestionSystem.cs:302-350`) handles inability to ingest at completion; local capacity remains its existing 50-unit limit and is not changed. Cancellation, authority/stale-source denial, recovery, and success do not emit this message.

## Output-window UI parity and editing adaptation

SS14 `Content.Client/Chemistry/UI/ChemMasterWindow.xaml.cs:170-212` calls `UpdateDosageFields` on each received state. That method recomputes dosage defaults and clamps/reassigns pill count, pill dose, and bottle dose from current source and output capacity. The local Output UI deliberately preserves numeric drafts when their relevant numeric inputs are unchanged, so label/type edits and periodic or unrelated acknowledgements do not erase choices. Its typed refresh signature is limited to selected draw source, exact source-volume cents, output kind, free canister cells, free bottle capacity, and pill dosage limit. When that signature changes, suggestions refresh through the existing form calculation; only a currently focused numeric draft is restored, and it remains subject to current snapshot validity rather than being clamped or sent. An explicitly typed or +/- adjusted pill dose is also retained across relevant-input changes; the pill-count suggestion is recomputed from that dose, the new authoritative source amount, and free cells. If that chosen dose is empty, invalid, unavailable, or above the current limit, the derived count is zero and packaging stays disabled rather than silently lowering the chosen dose. Only a user edit/adjust marks the dose explicit, not authoritative suggestions or native-editor synchronization. This is a client-local editing adaptation, not persisted server state or predicted inventory. Label behavior remains separate: `updateLabel=false` preserves the manual label, while `updateLabel=true` regenerates it from the authoritative selected source.

For the Minecraft rendering/input adaptation, `ChemMasterOutputEditors` positions native `EditBox` controls in the same logical field viewport exposed by `ChemMasterTextFieldPaint.viewport`; the overlay forwards logical pointer coordinates, and `ChemMasterPaint` paints the native display snapshot through the shared clipped painter. The pill-art helper uses verified opaque source crops for all 20 existing 32x32 sprites and one common scale per palette or contents context; the palette keeps uniform 10x2 button geometry, with naturally different silhouettes rather than per-type rescaling. Bottle reagent labels/colors are resolved through the same `ChemMasterOverlay.displayRows` path used for Input/Buffer reagent displays. These are Minecraft presentation/input adaptations; connected native caret behavior and owner visual acceptance remain separate evidence boundaries.
