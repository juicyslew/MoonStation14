# Cross-system regression contract (2026-09-23)

We missed reported issues because earlier checks were oriented around individual
handlers and happy paths, not cross-system source/sink conservation and cadence
boundaries. This is a durable verification contract, not a claim that this
document ran tests. Test names below identify existing evidence and its limits.

New reagent entry points and new status-producing prototypes must be gated by
explicit integration tests across their actual source, owner, sink, and cadence
where applicable—not only codecs or a support matrix. Keep this checklist in
the review/verification process. Physical ray hits, client rendering, and
multiplayer behavior remain manual risks; no launch is implied here.
