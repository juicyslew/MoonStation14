# Gas miner composition and adaptation

Reference: SS14 `Resources/Prototypes/Entities/Structures/Machines/Atmospherics/gas_miner.yml` and `Content.Server/Atmos/EntitySystems/GasMinerSystem.cs`, checkout `c9df5ef5d675b0d1d226828bddf6b78c28502d91`.

The resolved local profiles preserve the parent chain: `gas_miner_base` supplies 400 mol/s, 293.15 K, and 300 kPa; Oxygen/Nitrogen station profiles inherit their gas base and override the pressure cap to 1000 kPa; Plasma inherits the base unchanged. `maxTotalMoles` is represented as an effectively unbounded finite local limit. The live placed block entity resolves the typed profile and generates at 20 Hz into a proven finite room only. `AtmosphereService.generateFiniteGas` bounds each addition by rate, remaining total-mole capacity, and a pressure calculation after energy-conserving mixture, then uses the regular atmosphere publication path. It rejects exterior/unowned/unloaded locations and does not use trusted fixture initialization.

Upstream components are Clickable, InteractionOutline, non-colliding Physics fixture, Transform (anchored), Anchorable, Pullable, Sprite, AtmosDevice, and GasMiner. Local behavior represents the source composition and its atmospheric mutation only; Minecraft block collision and placement replace upstream interaction/physics/anchoring components, and no unsupported local components are fabricated. Upstream source has no APC power receiver; none is added. Generation is explicit resource creation per upstream spawn amount, not a periodic fixture refill. A regular block identity selects the resolved profile; no pipe ports are fabricated because the source has none.
