# Connected-player regression checklist

Sprint closed by owner confirmation on October 11, 2026. Retain these steps for
future regressions; not every listed scenario was individually witnessed.

Use the existing lifecycle-enabled test setup; this sprint does not enable its default-off gate. Two connected players are needed for the contention check.

1. Spawn an unclaimed villager, pig and several `/summon moonstation14:mouse`. Check white/brown/gray variants remain stable after reload and the authored model is grounded; mouse hitbox remains 0.4 × 0.3 × 0.4 blocks.
2. As a controlled character, run `/suicide`; verify the character dies, not the carrier. Use the existing ghost-on-move flow to enter a canonical ghost.
3. Run `/ghostroles` in ghost control. Check automatic cursor freedom, top-left placement, dragging and the top-right close button. Expand Pig/Villager/Mouse groups; click across each row, including its edges. Only live unclaimed bodies should appear, not your dead character. Check L-Alt/Escape restores capture and flight works.
4. Teleport to a listed body. Check you arrive above/behind it, facing it; remain the same ghost, can move afterward and do not rubberband.
5. Request each body in turn, dying/ghosting between claims. Walk several chunks away from the old carrier: terrain must render; repeat after F3+A or a render-distance change. Check mouse chat/bubble/squeak audio, smooth movement, faster running gait and prompt animation stop. `/give @s moonstation14:cheese_slice`, drop it into a puddle, then Alt+E/Alt+left-click the food as a mouse: eat the food, not the puddle; verify readable progress, no hands created and the consumed slice disappearing. Aim away from food to drink: stop at maximum hydration or full stomach; cheese must remain edible at maximum hydration. Mouse spacelube immunity is expected. Healthy mouse health should read 10/10; check authoritative Critical/Dead labels and the existing dead pose. Cheese-only hunger can hover near Starving under the pinned digestion rates; hunger maximum is 35, not 10.
6. Have both ghosts request one target together: exactly one controls it. Check a stale row or failed request leaves the loser a usable ghost.
7. Disconnect/rejoin while controlling a pig or mouse. Confirm the same body UUID is controlled, not a replacement human. Repeat death and another role claim.
8. Ctrl+Shift+F6 enters Creative through `/ms14dev creative`; Ctrl+Shift+F7 returns through `/ms14dev return`. From a mouse, repeat twice, including after flying far enough to unload its chunk: one return request must resume the same body with working movement and turning, without a second Creative toggle, chunk-loading/retry message or disconnect. While waiting, Creative inventory must remain untouched. Held keys must not repeat; screens/text fields suppress the chords, and non-operators remain denied. Bindings are configurable under Controls > Moon Station 14.
