# APC trip projection correction

`PowerRuntime.observeApcOutputs` no longer blacks out every indexed lamp when one APC trips. It immediately opens that APC's breaker, resets its cached output meter to zero (retaining the existing graph-known status and sample freshness), and schedules one bounded re-solve for the next server tick. That normal solve recomputes all indexed lamp projections by their resolved APC-tier component, so unrelated circuits and other closed APCs sharing a component keep their solver-computed supply.

The re-solve runs at most once on that next tick, even if the normal 20-tick cadence is also due. Its elapsed-tick argument is the full interval since the preceding solve, capped at the existing 20-tick maximum. Battery charge/discharge is therefore accounted once for real elapsed time; there is no zero-elapsed battery-only pass. The breaker is authoritative immediately, but lamp state can reflect the previous solve for less than one tick. The APC output sample is reset to zero on the trip-observation tick, and the re-solve refreshes samples normally.

Work remains bounded to the existing loaded-device index and existing topology solve. Chunk access continues to be guarded by `hasChunkAt`; no chunk is force-loaded. The unused runtime substation, APC, and battery-rate rating constants were removed because the live loop owns different actual caps/rates and no references to those constants existed.

The two added `ApcOverloadGameTests` described here are **synthetic solver-component tests**, not connected cable/world fixtures and not direct tests of the server tick scheduler: one proves a tripped component can be dark while a separate component stays lit, and one proves a healthy APC retains supply when sharing a component with an open/tripped APC. Existing protection meter-injection cases are synthetic as well. Later wired runtime-trip and topology-freshness coverage is recorded in [wired-proof.md](wired-proof.md) and [topology-freshness.md](topology-freshness.md); those GameTests do not turn this projection change into same-tick lamp blackout. The breaker changes immediately, while lamp state updates on the scheduled next-tick re-solve.
