## Implemented bounded path

- The COMMON `experimentalMindGhostControl` gate remains default-off and startup-sampled. Operators explicitly opt in with `/ms14 mindghost configure <body>` to persistently mark an eligible body for debug control, then `/ms14 mindghost start` and `/ms14 mindghost possess <body>`. This is operator-only experimental tooling, not vanilla click possession and not automatic joining or automatic control on login.
- Possession uses the server-authorized Offer / OfferReady / Begin / Ready / Commit handoff. The server selects/validates the target and maintains the body lease and no-AI ownership; the client does not choose ownership by claiming a target or position. The shared client intent, prediction, and replay route is used for the active harness, while Villager and Pig use the server-grounded world-step.
- Returning via `/ms14 mindghost return` creates a fresh ghost harness. A new ownership epoch rejects stale frames from the previous harness. Failure paths attempt cleanup/recovery rather than accepting stale ownership, but persistent lease failure and lifecycle cleanup are not yet proven robust.
- `host_entity_types` is retained **temporarily** for manual vanilla testing at the owner's request. Effective friction remains 20 and thermal behavior is untouched.
- Protocol version 3 is incompatible with other protocol versions: client and server must use matching builds.
