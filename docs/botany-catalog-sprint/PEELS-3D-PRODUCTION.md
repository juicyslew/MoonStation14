# Banana and mimana peel 3D production art request

Request ID: `botany-peels-3d-loose-production-20261028` (art-only; not an import authorization). Payload: `build/botany-catalog-validation/peels-3d-production/request.json`; scope/context manifest beside it.

Commission the **full, finished production pair** for banana peel and mimana peel as recognizable, loose, held, and inventory-native 3D item models. This is not a checkpoint/concept-only request. The owner explicitly requires peels to be 3D loose objects, not flat icons. Model a peeled banana skin: curved, open, irregular separated lobes, visible inner/outer surfaces and a low floor pose; mimana should match the form while retaining its own source palette. Actual authored geometry is required, not a flat icon extrusion. Preserve sensible native item scale: this is not jug-sized. Target <=96 quads per item; up to 192 only when needed for visible quality, not through destructive simplification or giant geometry trees.
