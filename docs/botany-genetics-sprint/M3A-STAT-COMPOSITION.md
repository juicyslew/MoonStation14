# M3A numeric and boolean stat composition

Pinned source verified at `c9df5ef5d675b0d1d226828bddf6b78c28502d91` (`C:/Users/William/Documents/SS14-dev/space-station-14`). `SeedPrototype` inherits `SeedData`; source `SeedData` defaults pest tolerance to 5, viable to true, and seedless to false. `PlantHolderSystem` consumes viability and pest tolerance; `SeedExtractorSystem` consumes seedless. The local composition places pest tolerance in `SeedProfile.Biology` and viable/seedless in `SeedProfile.Lifecycle`; codecs accept omitted fields with those defaults and retain explicit false values. Existing parent/default merge resolution remains owned by `SeedProfileMergeStrategy`/`PrototypeRuntime`.

`PlantStatMutation` is the reusable typed next-cycle API: choose `Target`, construct `numeric(target,min,max,steps)`, `integerYield(min,max,steps)`, or `toggle(VIABLE|SEEDLESS)`, then apply to immutable `GeneticValue` using the caller's `RandomGenerator`. It rebuilds only the affected typed subrecord and complete profile; packet, product, visual identity, chemistry, unrelated biology/lifecycle values and input instance stay unchanged. Float fields retain float storage and source midpoint-to-even bin rounding / weighted one-bin direction. Yield deliberately uses integer division before bin multiplication and changes the original integer by one, clamped to bounds. This unit does not own cycle scheduling, live instance replacement, random mutation tables, or runtime consumer wiring; those remain the next integration unit's boundary.

Bindings follow pinned `PARITY.md`: float ranges/5 steps are water .3–.9, nutrient .05–1.2, ideal heat 263–323, heat tolerance 2–25, toxin 1–10, low pressure 60–100, high pressure 100–140, pest/weed 0–15, endurance 50–150, lifespan 10–80, maturation 3–8, production 1–10, potency 30–100; yield is integer 3–10/5. Light and radiation mutation rules and water/nutrient requirement fields are intentionally absent. No species-specific flags are represented here.
