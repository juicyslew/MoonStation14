The resolved `SeedData` parent chain for each of the five currently composed local seeds (wheat, tomato, potato, poppy, aloe) contributes no `ConsumeGasses` or `ExudeGasses` entries; upstream `SeedData` declares both dictionaries initialized empty (`SeedPrototype.cs:140-143`). Clone and species-change copy both dictionaries (`:260-277`, `:322-338`). The upstream `PlantHolderSystem` reads the effective seed maps from the holder's seed. During the living cycle it checks each required gas against the mixture, increments `MissingGas` and skips consumption when that species is short; successful requirements are consumed by exact named species. Missing gas damages health once per missing entry. Pressure is evaluated after this consumption. Exudation follows environmental checks and uses `max(1, Round(amount * Round(potency) / entryCount))`. `MathF.Round` is midpoint-to-even. Gas exchange is once per plant cycle, not each tray tick. Sources: `Content.Server/Botany/Systems/PlantHolderSystem.cs:530-590`, `Content.Server/Botany/SeedPrototype.cs` (`SeedData` gas defaults and inheritance).

The local typed mapping extends immutable `SeedProfile` with stable `GasType`-keyed consume/exude maps, both defaulting empty. Gas mutation is represented by the typed `PlantGasMutation` payload and dispatched by `PlantMutationSystem` in the source table's original position; amount draw (`NextFloat(.01,.5)`) precedes a uniform pick over all nine canonical `GasType.values()` entries. The mutation changes the genetic profile only. The original 27-entry table order, odds, applies-to flags and nonpersistent mutation flags remain. World exchange is a separate follow-up consumer, not claimed here. Its adaptation boundary is strict sampled, finite-owned, loaded/passable cells through `AtmosphereService`; exterior ambient and unknown ownership are not physical writable sources. No genetics/world atomic transaction is implied.
