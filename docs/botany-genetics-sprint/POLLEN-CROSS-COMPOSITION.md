# Directional pollen-cross kernel

`PlantPollenCross.cross(donor, recipient, random)` returns a fresh immutable `GeneticValue`; it never updates a `PlantSeedReference` or either input. The plant-state owner must install the returned value in a newly-owned reference as its own operation. The kernel is a genetics operation only, not a swab/runtime or complete pollen feature.

Source pin verified locally: SS14 `c9df5ef5d675b0d1d226828bddf6b78c28502d91`, `MutationSystem.cs:59–195` (`Cross`) and `SeedPrototype.cs:260–315` (`Clone`). Source scalar fields choose recipient/donor with `Prob(0.5)`. Chemical entries choose donor/recipient oppositely; whole quantity records move together. Donor-only chemicals are added non-inherent; recipient-only entries retain the upstream removal draw even when sole, but sole entries are not removed. Gas entry draws have the opposite direction and are not floored. Local maps have no upstream dictionary-order contract, so this implementation uses deterministic sorted resource IDs and canonical `GasType` order; this intentionally adapts native dictionary iteration while retaining donor pass then recipient-only-removal pass.

The source scalar call order is preserved. Local model gaps (IdealLight, LightTolerance, WeedHighLevel, Ligneous, TurnIntoKudzu) consume their source 50% draws without introducing inert profile state. Mutation history has no local representation and remains an explicit unimplemented boundary; local `mutationTargets` are recipient metadata and remain unchanged (they are not mutation history). The final cross-species 70% seedless chance uses local species ID as the name-equivalent. These positions are draw-order compatibility, not gameplay parity for absent traits. Crossing retains recipient identity, products, visual and lifecycle metadata, and does not perform species-default resolution. Clone omits custom scream sound; accordingly the crossed profile keeps the existing default sound and −10 dB while crossing the scream-enabled scalar.

Remaining boundary before full pollen readiness: no swab carrier/action, timed interaction, runtime reference replacement, persistence/transfer behavior, or mutation-history feature is implemented here. No self-cross or viability guard is added.
