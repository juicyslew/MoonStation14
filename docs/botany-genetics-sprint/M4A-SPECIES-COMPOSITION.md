# M4A species composition

The seed profile's optional `mutation_targets` is an ordered, immutable list of local species prototype IDs. The typed seed merge strategy inherits the nearest declared list; a child declaration replaces it (including an empty list), preserving order and duplicates. Resolved profiles, not JSON-only data, are supplied to the instance transformation. The local catalog currently leaves these lists empty; no target leaf prototypes are registered by this change.

Upstream was verified at `c9df5ef5d675b0d1d226828bddf6b78c28502d91`. `Resources/Prototypes/Hydroponics/randomMutations.yml` declares ChangeSpecies, and `Content.Server/EntityEffects/Effects/Botany/PlantMutateSpeciesChangeEntityEffectSystem.cs` picks an ID from `Seed.MutationPrototypes`, resolves its `SeedPrototype`, then calls `SpeciesChange(protoSeed)`. The local Minecraft adaptation keeps a complete per-instance snapshot of acquired/local genetics rather than modeling unsupported SS14 component state: target identity, packet/product/visual and growth-stage count change; other lifecycle/biology and gases remain instance values. Target inherent chemistry is adopted if missing; obsolete source inherent chemistry is removed; acquired source chemistry and existing source entries remain.
