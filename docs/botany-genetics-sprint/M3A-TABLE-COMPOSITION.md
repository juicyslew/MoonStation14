# M3A3 random mutation table composition

Source: pinned SS14 `c9df5ef5d675b0d1d226828bddf6b78c28502d91`, `Resources/Prototypes/Hydroponics/randomMutations.yml` and `Content.Shared/Random/RandomPlantMutation.cs` (checkout recorded in [PARITY.md](PARITY.md)). The enabled source list contains 27 entries in authored order; the commented Bioluminescent entry is not imported. The local typed `PlantMutationTable` retains source odds, defaulted plant/produce/persistence flags, typed stat parameters, canonical chemical-table reference, and explicit capability identifiers for effects without an implemented consumer.

The stat mappings use the existing `PlantStatMutation` targets and factories, including integer Yield and boolean viability/seedless descriptors. `ChangeChemicals` points to the already-owned `randompickbotanyreagent` weighted table; reagent validation and resolution remain with `PlantChemicalMutation`. Ligneous, kudzu, screaming, gases, harvest, slippery, sentience, and species change are descriptors only where a concrete supported stat mutation does not exist; their identifiers are not evidence of successful application.

Table consumers must preserve authored roll order and perform a strict `< chance` test after source chance scaling, calling `NextDouble` for every entry even when chance is zero or one. Source effect probability defaults to one and uses a separate predicted-probability RNG; the current entries override none. This table-only unit introduces no mutation-cycle consumer or predicted RNG framework, and makes no live mutation parity claim.
