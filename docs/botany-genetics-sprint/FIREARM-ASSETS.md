No projectile/muzzle runtime consumer or rendering parity is claimed by packaging these images.

Note: All imported firearm RSI directory and PNG filenames are packaged lowercase under `textures/ss14/weapons/objects/...`; original metadata bytes/state IDs are preserved, with source state PNG filenames lowercased for case-safe resource lookup. Every model texture reference uses a lowercase `ResourceLocation` path without a `textures/` prefix (Minecraft adds that directory). Existing sources retain their original capitalization only in provenance references. Projectiles use lowercase IDs such as `ss14/weapons/objects/weapons/guns/projectiles/projectiles2.rsi/bullet`.

The projectile renderer uses a camera-facing Minecraft billboard (3D adaptation); where source `noRot` is false, it rotates the billboard in screen-plane to follow projected velocity, preserving the source sprite's up-axis orientation. `noRot: true` remains upright. This is not a native SS14 renderer claim.

Client presentation advances by tracked velocity once per tick between native entity position corrections; native `Entity.lerpTo` position updates snap rather than interpolate, while motion updates provide the tracked velocity. No client collision, damage, lifetime authority, or GPU/runtime parity is claimed; the server remains authoritative and corrections/removals come through normal entity tracking.
