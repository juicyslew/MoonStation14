The source chemical generation rule is Min plus potency/divisor only for positive divisor and potency, clamped to Min..Max.

Local mapping: resolved `ReagentData.plantMetabolism` flows through `PlantReagentMetabolism.poll`, invoked by the ordinary `HydroponicsTrayBlockEntity` evaluator callback. Unqualified source table IDs are lowercased and canonicalized into `moonstation14` by `ModWeightedRandomFillSolutions.canonicalId`; table filenames follow source spelling (`evilrandomfillsolution`, `randompickbotanyreagent`). `PlantChemicalMutation.prepare` validates every route against the resolved local reagent catalog before effects or source drain. Chemical mutation and existing produce generation use the narrow `BotanyFixedPoint` adapter for `FixedPoint2.New(float)`: `int(value * 100 + signed 1e-5)` with exact integer-cent addition. This preserves epsilon-adjacent cents, sampled minimum .01, and source order for Min + potency contribution before clamping to Max; unrelated `ReagentUnits.fromFloat` is unchanged. The tray changes only the immutable profile in `PlantInstance.genetics`, its revision owner. Harvest `ProduceFactory`, genetic item metadata, extraction and packet replanting consume that effective profile. `Chemical.inherent` defaults true for inherited prototype chemistry; acquired chemicals set false. Zero/nonpositive divisor or potency preserves Min. Chemical Min/Max accept the source nonnegative FixedPoint2 integer-cent domain (no local 10,000 cap); divisor remains finite nonnegative.

Adaptations/boundaries: entity-effect scaling is not modeled; the upstream chemistry effect's minimum scale is zero. Unsupported effects (including Vestine's toxin adjustment) remain reported. This unit does not implement random mutation-record rolls, gases, pollen, or other effects. Table reagent references are verified against the registered local reagent catalog at live consumption and fail closed before genetics mutation. Tables retain source groups and duplicate routes, never flattening them.
