# Manual machine UI gallery (client-only demo)

In a client world, type `/ms14_ui_gallery` in chat. This opt-in **local demo** is not connected to any machine or server state; opening it sends no gallery packet. Use the `x` in its title bar or Esc to close it. Try several GUI scales in Video Settings, resize the window, reopen the gallery and check clipping/focus at each scale. The owner manually found the gallery exciting and functional, but reported soft/blurred custom text and blank search rows despite working filtering. Subsequent code fixes and text contrast were **not visually retested**; the owner waived immediate visual checks and accepted that risk, not an empirically verified result. This docs worker did not run the client. See [owner feedback](owner-feedback-and-next-slice.md).

- **Search + field:** click the search box and type a substring; scroll the list, click rows, or focus it and use Up/Down. Enter an invalid number (empty, text, or above 100): `DEMO send` stays disabled. Enter a changed value in 0–100 and press `DEMO send`, then explicitly choose `DEMO confirm` or `DEMO reject`. Confirmation updates the local example; rejection restores the prior value. None of these operations writes to a server.
- **Slots + queue:** select/scroll slots; dragging does not move items, and these are text-only example slots, not an inventory. Choose a queue preset with the header arrows and click its name to emit an `APPLY_PRESET` demo intent. Select a queue row, drag to another row, or focus the queue and use arrows, E (enqueue), Delete (remove), R (reorder), Enter/Space (apply). The footer prints `NOT SERVER` for emitted intents; queue rows deliberately stay unchanged because no authority returns a snapshot.
- **Sample points:** drag to pan and use the wheel to zoom; focus the viewport for arrow-key pan and +/- zoom. Dots are fixed example points, not telemetry or an interpolated graph.

Tabs support click, keyboard focus with Left/Right then Enter/Space, and wheel. Resizing rebuilds layout while retaining the local draft, selected page, viewport and queue demo status. Very small windows can clip content; increase GUI scale only as far as the window remains usable. This gallery does not validate any connected machine, APC workflow, inventory transfer, or multiplayer behavior.
