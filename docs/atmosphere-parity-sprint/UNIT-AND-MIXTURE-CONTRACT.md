# Core atmosphere unit and mixture contract

Compared against SS14 `c9df5ef5d675b0d1d226828bddf6b78c28502d91`: `Content.Shared/Atmos/GasMixture.cs`, `Atmospherics.cs`, and `SharedAtmosphereSystem.Gases.cs`.

* The upstream tile is 2,500 L; a Minecraft cell is 1,000 L. `AtmosphereUnits.referenceTileQuantity` scales reference-tile absolute inventory and energy quantities by 0.4. It does not apply to temperature, pressure, ratios, per-mole heat capacity/heat, or numerical tolerances. Thus 0.01 mol => 0.004 mol and 143,000 J => 57,200 J.
* Mixture constructor's two-argument form preserves the existing one-cell API; the three-argument form carries explicit cubic-meter volume. Mixture pressure uses stored volume; the legacy pressure method remains an explicit-volume API. Zero volume yields zero pressure as upstream does.
* Temperature and simulated species/volume are stored as floats in immutable snapshots; legacy Map and numeric accessors remain widened to doubles. Aggregates traverse `GasType.values()` order with float accumulation. Temperature clamps to 2.7..262,144 K.
* `splitRatio` returns both cleaned remainder and packet, preserving volume and temperature on both. It uses float ratio arithmetic and omits species below 5e-8 mol from each side, matching upstream `RemoveRatio`; transport writers should consume the pair. `removeRatio` remains a packet-only convenience and does not itself update a value-object receiver.
* `heatCapacity()` reports physical raw SI Cp; `normalizedHeatCapacity()` matches upstream default capacity `max(raw/8, 0.0003)`. Merge uses these floored normalized capacities, >0.01 K and >0.0003 combined normalized J/K gates, with float arithmetic. `effectiveHeatCapacity()` is the raw-unit equivalent of that effective capacity. `thermalEnergy()` remains physical raw Cp × K; `simulationThermalEnergy()` is normalized Cp × K for parity kernels. Default AtmosHeatScale 8 divides both gas capacity and reaction heat, ordinarily cancelling in temperature calculations. Do not apply ×8 to local joules absent an external coupling contract.
* Upstream near-empty immutable reservoirs return normalized heat capacity 7,000; `spaceNormalizedHeatCapacity()` converts this to 2,800 for the local cell. This API exception is selected by immutability and near-zero moles, independently of the world's `Space` flag. Ordinary empty finite mixtures use the normal 0.0003 floor; gas-bearing immutable reservoirs use their gas capacity. Reservoir identity is not stored in this immutable value class; adapters supply it.
* `mergedWith(giver, giverNormalizedCapacity)` is the adapter hook for that virtual reservoir capacity. It affects only merge temperature weighting (including upstream's artificial reservoir cooling); only real giver species are added to the result. Pass this override only for an identified near-empty immutable giver; otherwise use the one-argument overload.

* Proportional world removal and finite/immutable breath sampling use the split contract, not plain species multiplication. A 2.3e-5 mol cell trace sampled at ratio 0.0005 produces a sub-cutoff packet species that is discarded; its approximately 2.29885e-5 mol source remainder is retained. The two sides are cleaned independently. Empty returned lung state is treated as no exhalation by the existing combined breath adapter; nonempty returned gas uses normal Merge.

Focused tests pin conversion and operation boundary cases against those source constants. Reaction prototypes retain canonical values; evaluation converts their reference-cell requirements once and compares at source-compatible float precision. This is not a cross-runtime bitwise-identity guarantee.

Production pressure transport intentionally uses current physical Cp and conservative thermal reconstruction rather than the archived/floored merge behavior as its transport oracle; source-reference kernels retain the contracts above. See `../pressure-transport-sprint/DECISIONS.md`. Long-run conservation validation must budget counted float operations and explicit trace cleanup, not just the final snapshots' ULPs.
