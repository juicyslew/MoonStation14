# Handheld analyzer manual checks

1. Hold **Gas Analyzer** in the active character hand and use it. The compact window
   defaults to **Target**. Use it again after changing distance: range and window
   placement must not reset. Moving it to the other body hand should retain the session.
2. While cursor-locked, wheel through distances 1–6 even if the old pointer position
   overlaps the window. Target data and outline must refer to the same cell. **At you**
   shows local gas without a distant outline; with the pointer unlocked, scroll either
   tab's gas list. Check compact text, separate list background and hand-item layering.
3. Scan through glass and then a solid wall: transparent examination vision permits
   the former; the wall stops the scan without showing a sample behind it.
4. Close the window, put away the analyzer, or switch body. The window, scan mode,
   outline and wheel capture should end. Verify chat/inventory and Shift-examine input
   still own their normal paths.

Post-R20 native/client execution and owner acceptance remain pending. CPU preview
review does not establish real GPU, input or audio behavior.
