# Singularity / emitter audio mapping

Verified against SS14 checkout `c9df5ef5d675b0d1d226828bddf6b78c28502d91`.

`Resources/Prototypes/Entities/Structures/Power/Generation/Singularity/singularity.yml` composes root `AmbientSound`: `/Audio/Effects/singularity.ogg`, volume `-4 dB`, range `14`. Separately, `Content.Shared/Singularity/Components/SingularityComponent.cs` supplies its own `AmbientSound` default: `/Audio/Effects/singularity_form.ogg`, loop enabled, `+5 dB`, max distance `20`; `FormationSound` is null; `DissipationSound` defaults to `/Audio/Effects/singularity_collapse.ogg`. `SingularitySystem.cs` starts the component loop at component startup and stops it on shutdown; a formation one-shot is only played when the optional formation sound is provided. Dissipation plays only on terminating/destruction, not unload. Local `SingularitySoundProfile` represents both loops and the optional formation/dissipation specifiers; a local entity-attached client loop follows the synced entity and profile. dB is converted to linear gain using `10^(dB/20)`.

Projectile audio composition follows the pinned `Resources/Prototypes/Entities/Objects/Weapons/Guns/Projectiles/projectiles.yml` parent chain: `BaseBullet` provides `FlyBySoundComponent` with sound `/Audio/Weapons/Guns/Miss/bullet_miss`, probability `0.10`, range `1.5`, and its projectile-hit sound `bullet_hit.ogg`. Local `ProjectileFlyByProfile` is the shared typed representation, defaulting to `moonstation14:projectile/fly_by`, `0.10`, `1.5`. PA particles resolve the inherited `base_bullet` profile; emitter bolts use their synchronized emitter prototype ID to resolve `bolt_fly_by` through the same default. Both adapters implement one common source interface and are consumed by one client-local swept-entry manager (no server fly-by dispatch). Minecraft adaptation measures 3D segment intersection against the listener AABB expanded by the profile range, and plays locally at the controlled character; this preserves SS14's short, probabilistic near-pass cue without broadcasting it.

The emitter prototype's `Gun.soundGunshot` is `/Audio/Weapons/emitter.ogg`; local resolved `EmitterProfile.fireSound` routes once for every actually created bolt through `ControlledSoundDispatch`. Local firing cadence remains the existing emitter burst scheduler. Emitter bolt contact audio maps inherited `BaseBullet` hit sound to the already-registered `moonstation14:pa_particle_hit` alias (same `bullet_hit.ogg`, no duplicate asset). SS14 `ContainmentFieldGeneratorSystem.HandleGeneratorCollide` contact is retained as a charged hit even when the generator rejects charge; the field generator fixture has `Fixture.Hard = true` inherited from `BaseStructure` (the containment fixture does not override it). The local bolt emits on field-generator contact and actual hard block contact, while non-hard contacts remain silent; this is based on the resolved fixture property, not a fabricated PA wall-impact rule.

Minecraft event sound definitions map to copied SS14 samples. Each local ambient loop uses the resolved profile's converted gain as its sole volume source; the sounds.json sample has no additional volume multiplier. Its resolved range independently admits/stops that loop, and the matching default sample attenuation distance is 14/20. If prototype authors override those ranges, Minecraft's sample attenuation metadata remains the authored default range, so non-default range attenuation has an engine limitation even though out-of-range playback is stopped. Source audio attribution gaps are listed in `docs/audio-unknown-provenance.md` without inferred authors or licenses. Minecraft attenuation curves and the shared controlled one-shot 32-block policy are deliberate engine adaptations; no continuous network packets are sent for loops.

Item-slot insertion/ejection aliases the existing Chemistry Master revolver magazine resources; SHA-256 comparison verified the other worker's copied files were byte-identical before deleting only those duplicate copies. Valve toggles map all three imported SS14 `Effects/squeak1..3.ogg` samples. Gas pressure-release and internals-connect mappings are deferred because their corresponding local capability/assets are absent.
