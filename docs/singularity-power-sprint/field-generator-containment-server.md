# Field-generator server projection (3D adaptation)

The server runtime indexes loaded `FieldGeneratorBlockEntity` instances by level and exposes independent `currentFaces` rectangular barriers as well as stricter `closedVolumes` six-face boxes. Each face is proven by four current corner placements and four valid edges, and exports axis/plane/extents/corners/placement UUIDs for a future renderer/replicator. A missing edge invalidates adjacent rectangles only; it does not erase unrelated field barriers. A closed volume still requires all eight corners and all twelve edges. `firstFaceHit` works over those independent faces, selects a two-sided approach normal, and suppresses parallel or moving-away contact; swept-sphere face contact expands face bounds conservatively at corners, rather than performing exact rounded-rectangle sphere collision. This 3D continuous rectangular-face adaptation is not SS14's planar generated field entity. It never forces chunk loads and has no global generator-count cutoff. Cached links bind endpoint placement UUIDs and are rechecked against loaded clear path geometry, profile distance, anchoring, and charge before reuse; this Minecraft obstruction policy is an explicit physical-world adaptation. Diagonal field edges and rendering/network synchronization are not implemented.

Parity reference: pinned SS14 `Content.Server/Singularity/EntitySystems/ContainmentFieldGeneratorSystem.cs` (`OnActivate`, `HandleGeneratorCollide`, `ReceivePower`, `LosePower`, `TryGenerateFieldConnection`). SS14 generates planar 2D connections from enabled, anchored, powered generators and retains a connection while either endpoint remains above its power minimum. This Minecraft adaptation extends the geometry to three axes to support a 3D eight-corner box; no claim is made that this is upstream behavior. Connections currently require same-profile generators, loaded clear axis-aligned paths, and the target endpoint anchored. Swept-face queries are geometry only: no singularity movement, reflection, or teleport/freeze fallback is provided.

Placeholder appearance uses vanilla iron-block texture. No field-face renderer is included.
