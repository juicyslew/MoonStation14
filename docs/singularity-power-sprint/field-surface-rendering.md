# Containment field surface rendering

`FieldFaceRenderer` consumes only `FieldFaceVisualCache` snapshots; server face geometry remains authoritative, and omitted faces are not synthesized. Generator topology/network integers remain block-position indices; `FieldGeometry.center` is the shared conversion to Minecraft world coordinates (generator block centers), used by contact, failsafe bounds, networking relevance and client face cells. Center anchors are an explicit Minecraft adaptation, not a new SS14 YAML component. The plane is emitted per face-cell as a continuous very-soft purple substrate with a white, untinted overlay sampled from the imported 32px SS14 field animation (16 frames, 0.1s per frame; see `containment_field.meta.json`). This is a Minecraft 3D surface adaptation, not SS14 directional RSI rendering.

The render callback remains at `AFTER_PARTICLES`. It emits through `Minecraft.renderBuffers().bufferSource()` using ordinary `RenderType.entityTranslucent` and flushes only the two render types it uses before leaving the stage. This intentionally relies on the level renderer's current target at that stage (the particle target in Fabulous); do not replace it with an emissive render type, manually bind targets, or move it to `AFTER_LEVEL`. Packed fullbright vertex light is a visual glow approximation only; it does not create Minecraft block light. The level renderer target/compositing behavior still needs an in-game cloud/Fabulous visual check; no GPU verification is claimed.
