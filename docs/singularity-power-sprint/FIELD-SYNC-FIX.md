# Containment face observer snapshots

Field geometry is still computed once per server level from `FieldContainmentRuntime.currentFaces`; delivery state is per player UUID. A newly relevant observer therefore gets the current complete face list even when geometry has not changed since the previous tick. Stable observers receive no redundant packets. Leaving the 128-block relevance radius sends an explicit empty snapshot, clearing the recipient's prior visual state. Login/logout and level unload clear recipient tracking. This changes transport bookkeeping only; face authority, geometry, payload codec and client cache remain unchanged.

Observer relevance uses shared `ObserverTracking.viewPosition`: validated medical ghost position remains first, followed by the existing `HandActorAuthority.resolve` controlled character body (lifecycle or harness) when it is present, exact, and in the player's level. Missing/stale context falls back to the native carrier; no action target/range gate is involved. The native carrier/chunk-center mechanics are not changed.

Field-generator empty-hand interactions through both native block use and controlled-body action now share the block entity's authoritative toggle result and localized status feedback. A connected enabled generator reports that it cannot be disabled; successful feedback includes enabled state, actual charge/max, and connection state. No charge is predicted. Focused source tests exercise the per-recipient snapshot relay through the payload codec/client cache and the view fallback; in-game GameTest/runtime validation remains outstanding.
