# Particle accelerator operator workspace
- With an empty hand, aim at an assembled accelerator control box and use the normal body-hand world activation; the workspace opens only for its matching accepted server response.
- Operational/incomplete, seven control/assembly positions, APC availability and authoritative power draw/received values reflect server snapshots.
- Use On, Off, Rescan, or Strength; controls wait for authoritative replies and strength labels map Standby/Level 0/1/2 (plus Level 3 only when the resolved maximum allows it).
- Close with X or Escape; changing controlled body, authority epoch, dimension, or logout clears the workspace. A manual reopen/control/power-outage/replacement/reach/authority-switch connected-client pass remains required.
- No Engineering access gate is implemented: authenticated controlled-body interaction is the local adaptation; upstream handler access restrictions are not claimed as parity.
- The control position is schematic and always shown; six physical positions are snapshot-driven placeholders, not imported PA artwork or a world scan.
