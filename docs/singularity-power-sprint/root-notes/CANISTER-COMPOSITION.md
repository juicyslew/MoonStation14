# Gas canister composition (domain-state slice)

The upstream inspection was against `c9df5ef5d675b0d1d226828bddf6b78c28502d91`, `Resources/Prototypes/Entities/Structures/Storage/Canisters/gas_canisters.yml`: GasCanister → BaseStructureDynamic → BaseStructure (which inherits Pullable), plus BasePaperLabelableVisualized → BasePaperLabelable. StorageCanister supplies empty 1.5 m³/293.15 K. `GasMaxPressureHolderComponent` defaults `releasePressure` to one atmosphere (101.325 kPa) and `minReleasePressure` to 10.1325 kPa; GasCanister prototype overrides `maxReleasePressure` to 1013.25 kPa. Concrete tank moles/temperatures vary by child (e.g. PlasmaCanister is not the only filled profile); do not infer all resolved profiles from the base. Local resolved defaults use the same 101.325 kPa release target with 10.1325–1013.25 bounds, valve closed. Appearance fields inherit a generic grey skin; StorageCanister overrides yellow and PlasmaCanister orange with a locked-default visual. These prefixes map to the accepted rounded-R2 `canister-import-manifest.json` families. Server sync derives pressure band (10, 101.325, 1519.875 kPa thresholds) from canonical gas and insertion from its UUID-owned slot. Client appearance readout stays absent until profile resolution. Lock is visual metadata only: no access reader/gameplay gate is implemented, a deliberate departure rather than access parity. Unsupported connector/labels/flap/integrity gameplay is not invented.

Validation covers resolved profile initialization, pressure/valve bounds and stale control revisions (`GasCanisterDomainTest`), plus native `gas-canister-entity` GameTests for registered-entity tick refill, species conservation, configured pressure target, slot token/metadata/ledger retention, saturation no-op, empty-slot no-vent, stale/inactive claims, and save/load after refill. The native persistence fixture uses a valid ledger source solely to exercise domain ownership and makes no claim to player/controller integration.

`GasCanisterEntity` resolves `ModGasCanisters.catalog(level)` and constructs/restores `GasCanisterState` using its entity UUID and `LevelItemLocationLedgers`; its proxy stack is presentation-only. The `gas_canister` resolved loose-object profile supplies 0.5 × 1 physical dimensions and mass; existing `LooseItemEntity` movement/tether logic consumes it. `LooseItemRenderer` is registered provisionally pending component-art binding. Body-hand transfer checks `LooseItemEntity.admitsBodyHandPickup()` and creative touch checks it too; the canister denies both. Malformed state remains retained as raw pending NBT and encoding failures fail closed. The verified `Entity.setRemoved(RemovalReason)` HEAD mixin dispatches lifecycle handling: destructive removals transfer the exact occupied slot payload via `BodyMachineItemSlotTransfer.ejectToWorldOwned` before vanilla detach and cancel removal on failure; non-destructive removals suspend ownership while preserving snapshot for save/reload. A removed entity's `canisterState()` is non-reactivating: it never resumes a pending claim, while save continues serializing pending state; only a live replacement can resume that owner claim. Refill cadence checks live level membership before state access. On server ticks the entity performs bounded finite transfer only from a compatible inserted tank; a missing tank never vents into void. Transfer commits through existing `MachineItemSlot.mutate`, retaining its token/ledger claim and component metadata while incrementing slot revision. Refill runs once per 20 entity ticks (nominal 1 s at Minecraft 20 TPS) so it does not apply the instantaneous SS14 `ReleaseGasTo` cap twenty times per second. Upstream `GasCanisterSystem.DeviceUpdated` is driven by `AtmosDeviceUpdateEvent` with `RealAtmosTime()` (processing-state count × `AtmosTime`, excluding disabled states and subject to skipped device processing), not a fixed per-entity tick; this coarse cadence is a deliberate standalone-runtime adaptation, not exact event-timing parity. Refill UI controls, world-environment endpoint, venting, reactions, pipes, and radiation remain deferred.
