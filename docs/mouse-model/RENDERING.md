# Mouse authored model integration

The accepted R2 model, animation classes, and six textures are installed at the exact Java/resource destinations in the asset package's `export/manifest.json`. Model layer registration is wired through `MouseMobRenderer.registerLayer`; the existing `ModEntities.MOUSE` renderer registration now consumes the authored rig.

R2 defines geometry in canonical 16-units-per-block with its own root Y=24 alignment. The renderer therefore adds no scale or vertical translation. Bounds include ears and tail (7.6054 x 6.0594 x 8.5973 model units); the existing 0.4 x 0.3-block physics collider is intentionally unchanged. R2's six materials are retained as resources. The resolved `MouseAppearance` character component permits white, brown, and gray coats; the authoritative entity selects one once, persists it in entity NBT, and synchronizes it to clients. White remains the default when no variant is initialized. Normal and dead textures use the matching authored color; no renderer-side randomness or vanilla corpse rotation is used.

The existing synced MobState attachment selects critical `down_hold` with normal white material, or dead `down_hold` with the white dead/splat material and gore. Vanilla corpse rotation is suppressed. Other living states use immediate horizontal body-position delta (`getX() - xo`, `getZ() - zo`) to choose the existing R2 `run`/scurry clip while moving and idle when stationary; this bypasses vanilla's smoothed `limbSwingAmount` stop tail and does not depend on `isSprinting`, which controlled mice need not mirror. The user-requested presentation adaptation uses the existing 0.2-second scurry rather than native 0.6-second walk, so visual stepping cycles at 5 Hz; gameplay walk/sprint speeds and physics remain unchanged. No additional movement smoothing or gait phase clock is introduced. Advanced optional clips remain host integration work. These are deliberate limits, not claims of complete mob gameplay parity.

Attribution and CC-BY-SA-3.0 provenance are preserved adjacent to the transferred textures in `src/main/resources/assets/moonstation14/textures/entity/mouse/ATTRIBUTION.md`; source ancestry/details are in the asset package's `ATTRIBUTION.md` and README. No R1 art was mixed. Upstream behavior evidence is recorded in the package handoff; local type is a Minecraft adaptation.
