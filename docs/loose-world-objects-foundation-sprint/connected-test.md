# Connected check

Use a disposable world and a controlled character. Prepare filled/empty jugs, an ordinary item, a grenade and a storage bag through the existing item setup.

1. Q-drop a jug. Check recognizable 3D shape, fill level, floor contact, no bobbing/spinning at rest, fractional placement and unobstructed walking through it.
2. Overlap several dropped objects. Aim at the pile, cycle with **]**, confirm the name/index cue, then left-click with an empty hand. The indicated member—not a different pile member—must be picked up. Repeat with two connected actors competing for one object.
3. Hold a filled jug and target an empty loose jug. **E** transfers into the target; **Shift+E** reverses transfer. With an empty hand, Shift+E sips from the loose jug; **Z** sips the held jug. Check amounts, cooldown and no lost container.
4. **Ctrl+Q** throws an ordinary item, then a jug. Q must not also drop. Check spin/settling; a qualifying jug impact spills/breaks, not midair. **Z/N** primes a grenade; **Ctrl+Q/M** throws it. Its original fuse must continue on the ground.
5. With an empty hand, **P** (or Ctrl+left-click) pulls the selected object. Check the hand indicator, bounded wall collision, stop, and stopping after switching hands. Check cleanup on stun/body exit; the object must never become a held copy.
6. Keep a bag window open through held↔world transfers and world motion. Exercise other-hand insertion, rotation and manual cursor mode. UI clicks must not perform world use/pickup/pull.
7. Save/restart and reload the area. Check object contents, position/orientation and no stale pull reservation. Check unrelated vanilla/Creative drops still have their original rendering and pickup behavior.

Controls are rebindable where registered; pile cycling and P are Minecraft usability adaptations. This checklist is owner-connected acceptance, not evidence that it has already been run. Software model diagnostics do not replace these viewport checks.
