Moonstation 14
=======

Hi. This project is an attempt at porting SS14 to Minecraft. If I ever get it into a playable state, I'll release it in a more usable form. Until then, feel free to peruse this repo, or fork it, or whatever you want honestly. The world is your oyester.

Purpose Of This Repo
=======
Assuming I finish, this repo is intended to be as faithful of a re-imagining of Space Station 14 as I can manage. The only new mechanics or concepts introduced are those necessary due to the 3D nature of minecraft. For example, there are some features around giving you information about things outside your viewport, the goal being to make the game less disorienting from a first-person perspective.

IF this is successful, I MAY attempt to add my own extensions, or even start porting features from Space Station 13 rather than 14. If I do so, though, that would be a fork or separate repository from this one.

If YOU want to take this work and add things on top of it, you COULD make a mod with this as a dependency, but I wouldn't suggest it. I did not design this with mod compatibility in mind. Rather, if you want to make extensions of this, feel free to fork this repo, add your stuff, and publish the mod once more. At least leave an attribution for me tho <3.

If this gets enough support, then I can consider mod compatibility, but so far my only concern has been getting across the finish line.
